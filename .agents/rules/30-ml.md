# Rule 30: Machine Learning & Benchmark Pipeline Standards

**Activation:** Always On

## 1. Model Architectures & Frameworks
- PyTorch 2.8.x & MONAI 1.5.x for 2D slice-wise medical image segmentation.
- Target Architectures:
  1. U-Net (`monai.networks.nets.UNet`)
  2. U-Net++ (`monai.networks.nets.BasicUNetPlusPlus`)
  3. Efficient-UNet (`monai.networks.nets.FlexibleUNet(backbone="efficientnet-b0")`)
  4. SegResNet (`monai.networks.nets.SegResNet(spatial_dims=2)`)

## 2. Evaluation Metrics & Profiling
- Metrics: Per-class 3D Dice and Mean IoU computed across foreground classes (LV, RV, MYO), excluding background.
- Hardware & Profiling: FLOPs measured at fixed standard dimensions (1x1x160x160). Latency protocols measured using 5 warmup runs + 30 timed runs.
- Model Export: ONNX format (`torch.onnx.export` opset >= 17) with numerical parity verification against PyTorch.
